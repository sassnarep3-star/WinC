Disclosure, links, and the publishing gate

This page is the operating manual: what we disclose, how every outbound link is marked, which rules come from which official document, and what must pass review before anything new goes live.

1 · The disclosure (above the fold, every page)

The strip

“Advertisement — As an Amazon Associate we earn from qualifying purchases.” plus a link to this page.

It sits directly under the masthead on every page — including this one — so it’s visible without scrolling, and it repeats in the footer of every page. The wording follows Amazon’s required Associates statement; the placement follows the FTC’s rule that disclosure be “placed so it’s hard to miss” and sit with the endorsement itself.

Sources: FTC — Disclosures 101 ↗ (placement, simple language) · Associates Operating Agreement ↗ (program participation).

3 · Special Links: the current decision

Amazon’s Operating Agreement defines Special Links as links that “properly use the special ‘tagged’ link formats we provide,” and the Program Policies state the Associates tag (format XXXXX-##) must appear “as a parameter in the URL of each link you place on your Site.”

  • Buyer CTAs use: https://www.amazon.com/dp/<ASIN>?tag=shopnow047c-20 — the documented tagged format, observed destination ASINs only.
  • Supplied link.amazon/… codes: recorded in the register with their observed redirect targets, not used as buyer CTAs. Their compliance status is unresolved — not claimed invalid (FLG-002). Decision card: S-01; validation test: S-02.
  • Tracking ID shopnow047c-20: format-valid, account-unvalidated (FLG-004); the S-02 one-link-per-product test is the gate before scaling.

Sources: Operating Agreement ↗ · Program Policies ↗

4 · The publishing gate (what every new page must pass)

Before a guide publishes

  1. Disclosure strip present at top? ✓ required
  2. Every product fact sourced to an official page, dated?
  3. Manufacturer claims labelled as claims?
  4. No untested “we tested / we tried” language?
  5. All outbound product links rel="sponsored" + visible tag?
  6. Sources block at the end?
  7. Added to sitemap.xml + feed.xml?

Before a register value publishes

  1. Read from an official source on a recorded date?
  2. Source URL in the same row?
  3. Intent ≠ observation — separate fields?
  4. Can’t confirm → blank + ✱ + flagged (never inferred)?
  5. Volatile value → dated snapshot + live link?

5 · What we deliberately don’t do

  • No fabricated metrics. No conversion scores, revenue forecasts, or popularity claims — the campaign ledger is empty until first-party reports exist (FLG-006).
  • No hidden affiliation. Disclosure never gets buried in a footer alone; it leads every page.
  • No unverifiable superlatives. “Best,” “#1,” “cheapest” don’t appear as our claims; when a badge like Amazon’s Choice is shown, it’s attributed to the listing and dated.
  • No hot-linked Amazon imagery. Editorial images are original to this site (see S-07).
  • No claim about the supplied short links’ validity either way until Associates confirms (FLG-002).

6 · Review cadence

The brief’s compliance gate (S01 · S07 · S24) runs on every publish: disclosure placement and endorsement context are checked against the Operating Agreement and FTC guidance using the checklist above, and any new irregularity lands on the Flagged for review page the same day. Sources are re-read whenever Amazon updates its policy pages (the Program Policies page showed “Updated: April 14, 2026” when we read it).

Open compliance items

FLG-002 (supplied-link status), FLG-004 (tag validation), and suggestion S-02 (one-link test) are the outstanding gates before link scaling. They don’t block the site’s launch — they block scaling, which is exactly how the gate is meant to work.
