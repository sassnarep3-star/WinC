How to use this page

  1. Read a card: the yellow box is the decision.
  2. Pick Path A or Path B (or write your own in the repo — see open questions).
  3. Record the choice — reply with the suggestion ID (e.g. S-04) and the path. Implementation follows the choice, not the other way round.

S-04 · Where click & conversion measurement actually lives

Awaiting decision

Shipped: a privacy-preserving client-side counter recording five events into localStorage only (no cookies, no third parties) — see the metrics panel. Missing: any server-side endpoint (static hosting has none), and conversions can only come from Amazon’s own reports.

Path A — keep local-onlyZero infrastructure; events stay in the reader’s browser (so they don’t aggregate across readers — honest but weak).
Path B — self-host a tiny endpointe.g. a worker/serverless function on your own domain receiving sendBeacon posts; enable the existing ENDPOINT_OFF flag; define the canonical five events (FLG-007).

Decision: local-only, or stand up a self-hosted endpoint? And confirm the canonical five events.

Effort: A none / B half-dayImpact: decisions depend on it
