Before enabling collection

  1. Choose a host capable of a first-party endpoint; set authentication, rate limits, retention, backup and access controls.
  2. Review privacy notices, consent obligations and regional requirements with a responsible reviewer. This page is not legal advice.
  3. Document the exact event schema and purpose. Use aggregate reporting wherever possible and test data deletion/retention.
  4. Connect Search Console only after the site property is verified; search queries and impressions are measured only from its actual reports.
  5. Validate one click test and an authorized report import end to end; record the test and date before calling measurement live.
