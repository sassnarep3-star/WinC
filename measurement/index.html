Machine-readable version: data/ledger.csv. Written only by npm run ledger:add-style tooling with a source argument, never by hand-editing a number into a page.

Reporting rhythm

  • Weekly — desk note: pages added, rows still unresolved, gate failures, ledger rows recorded if a report was read.
  • Monthly — cluster review: which question got impressions; the next topic is picked from that, not from preference.
  • On event — any stale product row (30 days) triggers a re-check or removal, because that is the rule, not a nicety.

What we will not publish: a conversion rate, an estimated EPC, or a revenue forecast. Each needs inputs this desk is either not permitted to hold or has never seen, and a number that cannot be defended is worse than an empty cell.

GitHub Pages logs visitor IP addresses for security (SRC-09), so 'we collect nothing at all' would be false. That is why the privacy page says “we send nothing” rather than “nothing is recorded”.
