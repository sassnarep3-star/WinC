Why the AI pipeline is smaller than the brief implies

Two published constraints shape it, and they are worth stating before anyone builds an agent.

  • Program Content and Special Links may not be used to develop machine-learning models or related technology without Amazon's prior written approval.
  • Product data access runs through the Creators API, which requires an enrolled account and at least ten qualifying sales in the past thirty days; the older PA-API 5 endpoint returns 403 Forbidden.

So the automatable part of “AI-powered” here is generation and hygiene: drafting structure, validating identifiers, keeping the sitemap and feed true, refusing a page that contains an unsourced claim, and queueing stale rows. The part that is not automatable from a repository is acquiring the facts — and pretending otherwise is how affiliate sites end up with invented prices.

Sources: SRC-02 §5, §6(s), SRC-05, SRC-06.

Build & deploy

The site is generated, so the HTML you are reading is an artefact, not a hand-written file. Commands:

  • npm run build — regenerate every page, the sitemap and the feed
  • npm run check — the gate: links, disclosure, sponsored rels, tag presence, price/rating patterns, sourced cells
  • npm run verify — build, then gate; this is what CI runs
  • npm run serve — preview at http://localhost:8080/WinC/ with the same sub-path as Pages

Deployment is GitHub Pages, publishing from branch main at / with a legacy build, which is why generated HTML sits at the repository root rather than in a docs/ or dist/ folder.

Sources: SRC-09, SRC-10.
