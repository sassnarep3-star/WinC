FLG-001 · Submitted codes don't match the official ASIN format

Observed: all five path codes are 9 characters with lowercase letters (B04G1MEwY, B02NbDxp3, B00hJ57DV, B0c8moW59, B0f3GKalj), and amazon.com/dp/<code> failed to load for each while two known-good controls loaded fine — same day, same method.

Why it matters: Amazon states "An ASIN is always 10 characters long" — so these cannot be complete ASINs as defined.

Review needed: confirm with the link provider whether codes are truncated; map each to its true ASIN.

Sources: Amazon Ads targeting guide (ASIN definition) · observations O-06, O-07

Blocks: product identityRelated: FLG-002, Q-01Opened: 2026-11-20

FLG-002 · Intended codes and observed redirect targets mismatch on all five links

Observed: each submitted link landed on a real Amazon listing whose /dp/ code differs from the code in the link path — e.g. B04G1MEwY → B0CDY277D3 (air fryer), B0c8moW59 → B0DHZTCNR5 (thermometer).

Why it matters: the register stores both fields separately on purpose; merging them would silently misattribute every product.

Review needed: owner states which side is authoritative per row (path code vs landing listing).

Sources: observed listing P-01 · observed listing P-04 · full record

Blocks: product copy, catalogRelated: Q-02Opened: 2026-11-20

FLG-003 · Compliance status of the supplied short links is unresolved

Observed: link.amazon/… links redirect into Amazon product pages, but whether they satisfy Amazon's "tagged" Special Link format cannot be determined from outside the Associates account.

Why it matters: Amazon requires Special Links for commission tracking (V-02), disclaims fees on improperly formatted links (V-05), and prohibits shortening that makes the Amazon destination unclear (V-08). We do not claim the supplied links are invalid — their status is simply untested.

Review needed: SG-19 one-link-per-product test inside the enrolled Associates workflow; record destination + tracking-report confirmation here.

Sources: Operating Agreement §1 · Program Policies §2(b), §6(w)

Blocks: SG-06 link swapRelated: Q-06Opened: 2026-11-20
