About and method

WinC Kitchen Picks is a working name for a static, source-first buying guide. Values come from the pages named in the register, with the date of capture.

How values are checked

  • Each product page is read with a fetch tool on 2026-11-20. Values are copied as shown.
  • Counts and ranges on the Analysis page are computed in the build from the stored values.
  • Anything that cannot be confirmed is left blank and shown as Unverified, with a flag.

Limits of this review

  • Pages were read without a logged-in or local session (F-12).
  • The sandbox could not reach link.amazon directly; the fetch tool was used for the redirects.
  • Policy clauses 2(b), 2(v), and 2(w) were read from official search excerpts; a full-page check is pending.

Analytics status

No analytics or click counter is installed. The site is static (GitHub Pages), so no server endpoint exists. See Flagged for review F-08 and Suggestions S-02, S-03.
