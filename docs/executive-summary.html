The five things that need a human

decision queue

1 · Product identity — which side is authoritative?

Fact
All five links' path codes (9 chars, don't resolve) differ from the listings they open (real, 10-char ASINs). FLG-001, FLG-002
Decision
Confirm intended product per row with the link provider → unlocks product copy and catalog work.

2 · Link compliance test — SG-19

Fact
Supplied short links reach Amazon but their Special-Link tagging is untestable from outside the account. FLG-003
Decision
Run the one-link-per-product test in Associates Central (~30 min) → unlocks SG-06 link swap and attribution trust.

3 · Analytics hosting — SG-12

Fact
Endpoint code is ready; nothing is deployed; events currently live in-browser only. FLG-006
Decision
Pick Cloudflare Worker (recommended) / VPS / stay local → unlocks aggregate click data and A/B tests.

4 · Search Console verification — SG-29

Fact
Site is indexable; property unverified; zero query data exists. FLG-007
Decision
Provide HTML tag or DNS verification → unlocks the 30-day query loop that picks the next guide topic.

5 · Domain strategy — SG-26

Fact
Canonicals point at the GitHub Pages URL; a custom domain costs ~€10–15/yr and changes Search Console strategy. FLG-010
Decision
Buy now, stay put, or decide after first data — affects canonicals, property verification and brand trust.
