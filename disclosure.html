Disclosure: how this site earns money

Plain language, above the fold, on every page — because you should not have to hunt for it.

By the ShopNow Kitchen Desk · Updated 2026-11-20

As an Amazon Associate I earn from qualifying purchases. When you click a link marked Sponsored and buy on Amazon, this site may earn a commission at no extra cost to you. This statement appears under the masthead on every page and again in the footer (Operating Agreement §5, S01; link-level disclosure per S07; FTC clear-and-conspicuous standard, S03).

What this means

  • Sponsored links: every outbound product link carries rel="sponsored nofollow" (Google, S04) and a visible Sponsored label.
  • Prices: this site does not display prices. Prices and availability are shown on Amazon (Program Policies, S02). “Check price on Amazon” is the only price action.
  • No endorsement, in either direction: an affiliate relationship does not mean Amazon endorses this site, and this site is not endorsed by, sponsored by or affiliated with any brand it names. Program Policies §6(d) forbids using Program Content — “including any name or likeness embodied in that Program Content” — in a way that implies an endorsement or a commercial tie-in (S27). Brand names appear here to identify products, and nothing else.
  • What we take from a listing, exactly: the title string and the product-detail values, each reproduced with the URL and the date it was read. Program Policies §6(a) allows truncating that text where the meaning is unchanged and forbids altering it, so the verbatim title always sits under the shortened shelf label (S27, Q-23). No listing image, banner or description paragraph is copied, and no Amazon graphic is resized and reused.
  • Guides are original: the analysis, the checklists and the questions are written here. What is quoted is marked as a quote and linked.
  • Privacy: no cookies, no fingerprinting, no email storage on this static site. Measurement counts aggregates only (see Measurement). Reader-capture emails are handled by the email provider you choose.

Compliance gate

Every build runs scripts/check_site.py, which fails if: any page lacks the disclosure strip, any product link lacks rel="sponsored" or the Sponsored label, any price is rendered, or the sitemap is incomplete. The gate is the publishing workflow — not a suggestion.

Two obligations this page now states out loud

  • If Amazon takes a listing down, the copy here has to go. Program Policies §6(c) requires prompt removal of Program Content “that is no longer displayed on an Amazon Site” (S27). scripts/freshness.py publishes how old every recorded read is and fails past a hard limit, so a stale page is visible rather than quietly trusted. The takedown itself is a human action, and that is recorded as an open process (FLG-027, Q-24).
  • Nothing collected here trains a model. Program Policies §5 bars using Special Links or Program Content “to develop machine learning models or related technology” without Amazon’s express prior written approval (S27). This repository automates rendering, checking and record-keeping; it contains no crawler and no corpus export, and the ban is written into the standing rules so a future pass cannot drift past it (Q-25).
